# Registration Form – Bootstrap Practice

This is a simple Registration Form page created to practice Bootstrap concepts in GitHub Codespaces.

## Purpose

The goal of this project was to practice:

- Creating a structured form layout  
- Working with different input types  
- Understanding spacing and alignment  
- Applying Bootstrap layout concepts  
- Practicing responsive design basics  

## Technologies Used

- HTML5  
- CSS3  
- Bootstrap  
- GitHub Codespaces  

## Features

- First Name & Last Name fields  
- Gender selection (Radio buttons)  
- Date of Birth input  
- Address textarea  
- Hobby selection (Checkboxes)  
- Contact number validation  
- Password and Confirm Password fields  
- Submit and Reset buttons
